NORMS.md is part of every agent's brief. An agent reads it when a conversation starts, so a change reaches each agent on its next fresh conversation (python -m agyteam.supervisor --cycle-all makes that now).

Memories

Each agent's own memory, with its history: how long it has been known, how often it was rewritten, how often the agent read it back. What you write here it reads as its own, marked as written by the operator. A review is a turn in which the agent goes over its memories and merges, rewrites and deletes; it runs on its own at milestones and weekly, between the agent's turns. Nothing removed is lost: it is in the archive below.

Tasks

Tasks form a tree: a project is a task with tasks under it. Levels say how big a task is: . A team can rename them with "task_levels" in its roster.

Project labels into parent tasks

Each project label becomes a top-level task at level 1, with the label's tasks under it. A label whose tasks are all closed becomes a closed, archived parent, out of view. Labels stay on the tasks.

Update & restart

Update brings agy-team and agy-chat to their newest code, then restarts every running team gracefully: no new turns start, mail keeps queuing, the turns in flight finish, and each supervisor restarts itself on the new code. Then agy-chat restarts and this page reloads. Nobody has to catch the team idle.
