Agents

Changes go to the roster through agy-team, so a running supervisor adopts them. A removed agent's turn is cancelled; its memories and history stay on disk. Workspaces and other policy fields are edited in roster.json.

Norms

NORMS.md is part of every agent's brief. An agent reads it when a conversation starts, so a change reaches each agent on its next fresh conversation (python -m agyteam.supervisor --cycle-all makes that now).

Memories

Each agent's own memory. What you write here it reads as its own, marked as written by the operator.

Update & restart

Update brings agy-team and agy-chat to their newest code, then restarts every running team gracefully: no new turns start, mail keeps queuing, the turns in flight finish, and each supervisor restarts itself on the new code. Then agy-chat restarts and this page reloads. Nobody has to catch the team idle.
